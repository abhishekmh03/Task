# Image Processor App
Link => https://task-j9xu.onrender.com

This is a full-stack image upload and processing application built with React (Frontend), Express (Backend), Multer (File upload middleware), and Cloudinary (Cloud-based image storage and transformation).

## 🚀 Features

- Upload images from the frontend
- Store and retrieve images from Cloudinary
- Resize uploaded images to 512x512
- View both original and processed versions
- Download processed images
- Responsive UI design for desktop and mobile

## 🛠️ Technologies Used

- React
- Express
- Multer
- Cloudinary
- Node.js
- CSS
